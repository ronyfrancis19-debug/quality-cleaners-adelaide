# Quality Cleaners, Adelaide

Static one-page website for Quality Cleaners, a domestic and commercial cleaning business in Adelaide, South Australia.

## Preview

Open `index.html` in a web browser. No build step or server is required.

## Service pages

Each service has its own page under `services/`. To add a video later, drop the MP4 into `videos/` using the filenames listed in `videos/README.txt`.

## Hero video

The homepage uses `videos/hero.mp4` (and optional `videos/hero.webm`) with `images/hero-poster.jpg`. Playback is muted, looping, and paused automatically when `prefers-reduced-motion: reduce` is set.
